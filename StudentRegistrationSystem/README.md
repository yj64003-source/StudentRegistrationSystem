
# Student Registration System

## Project Description
A Java Swing-based Student Registration System developed for OOP CIE-2 Activity-6.

## Features
- Student Registration
- Student Details Validation
- Search Registered Students
- Delete Student Records
- Division-wise Statistics
- Dark-themed User Interface

## Technologies Used
- Java
- Java Swing
- AWT
- Event Handling
- Layout Managers

## How to Run
1. Install Java JDK.
2. Open the project folder in Antigravity or VS Code.
3. Open the terminal.
4. Compile the application:

   javac StudentRegistrationSystem.java

5. Run the application:

   java StudentRegistrationSystem
